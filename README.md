# OKX Adaptive Trader | Публичный канал обновлений

Этот **публичный** репозиторий предназначен исключительно для доставки подписанных файлов обновлений. Код программы и данные пользователей хранятся отдельно в приватном репозитории.

**Статус:** подписанных выпусков нет. Публичная HTML-страница носит только информационный характер. Отсутствие `channel.json` означает, что автоматическое обновление пока недоступно.

## Правила публикации

1. Никогда не добавлять сюда приватный Ed25519 ключ, PEM, пароли, API-ключи, owner.token, дампы SQLite/WAL, конфигурации пользователя и журналы с чувствительными данными.
2. До публикации `channel.json` необходимы подтверждённые нативная приёмка, корректный запуск GUI, сохранение финансовой истории и проверенный rollback.
3. Файлы выпуска должны проходить проверку Ed25519 и SHA-256. Один лишь HTTPS не удостоверяет происхождение обновления.
4. Не переносить код из приватного `okx-adaptive-trader` в этот репозиторий.
5. Не редактировать опубликованный релиз так, чтобы менялось содержимое по прежнему адресу.

## GitHub Pages

В настройках **Settings → Pages → Build and deployment** выбрать **Deploy from a branch**, ветка **main**, папка **/(root)** и **Save**.

После включения Pages и успешного деплоя предполагаемый адрес: `https://f6dtv6bnwg-debug.github.io/okx-trader-updates/`. Он должен быть проверен фактическим HTTPS-ответом, прежде чем использоваться для выпуска.

Не публиковать `channel.json` с фиктивными подписями, тестовыми private key или искусственно выставленными approval flags.
